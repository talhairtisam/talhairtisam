# Development

This repository serves two purposes:

1. **`README.md`** — displayed on [github.com/talhairtisam](https://github.com/talhairtisam) as the GitHub profile README
2. **`src/`** — Next.js portfolio site (App Router, TypeScript, Tailwind CSS)

## Local setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command        | Description              |
|----------------|--------------------------|
| `npm run dev`  | Start development server |
| `npm run build`| Production build         |
| `npm run start`| Run production server    |
| `npm run lint` | Run ESLint               |

## Deploy

Deploy to [Vercel](https://vercel.com) from this repo root. No root-directory override is needed.

When the site is live, update the portfolio URL in `README.md`.
